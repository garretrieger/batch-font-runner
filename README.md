# batch-font-runner

## Collecting a list of fonts

For example using the google fonts repo:

```sh
find $HOME/src/fonts/{ofl,apache,ufl}/ -iname "*.[ot]tf" > fonts.txt
```

## run_hb_depend_parity_check.py

Helper to run `hb-depend-closure-parity` on a collection of fonts in parallel. Reports any found under
approximations to stdout. Example execution:

```sh
python3 run_hb_depend_parity_check.py  -n 100 -j 90 --checker-path=$HOME/src/harfbuzz/build/test/fuzzing/hb-depend-closure-parity fonts.txt > under-approx.txt
```

Sample output:

```
UNDER-APPROX on ../fonts/ofl/padauk/Padauk-Bold.ttf for test ID 0xeddbddde0ee2ed74
UNDER-APPROX on ../fonts/ofl/padauk/Padauk-Regular.ttf for test ID 0xeddbddde0ee2ed74
...
```

## compare_runs.py

Tool for comparing two trials from an IFT segmenter dataset (generated by `run_gen_ift_segmentation_plan.py`).
It parses `out.scsv` and optional `error_log.txt` / `NOTES.txt`, builds a structured in-memory model of the
comparison metrics, and can output either a formatted terminal text report or a standalone interactive HTML dashboard.

### Testing and Building with Bazel

Run unit tests:

```sh
bazel test -c opt --test_output=errors //:compare_runs_test
```

Build the binary:

```sh
bazel build -c opt //:compare_runs
```

### Usage

Generate a text report to stdout:

```sh
./bazel-bin/compare_runs <dataset_dir_or_scsv> <control_trial> <candidate_trial>
```

or via `bazel run`:

```sh
bazel run -c opt //:compare_runs -- <dataset_dir_or_scsv> <control_trial> <candidate_trial>
```

Generate an interactive HTML dashboard:

```sh
./bazel-bin/compare_runs <dataset_dir_or_scsv> <control_trial> <candidate_trial> --html -o comparison.html
```

Filter by a specific quality level (e.g. quality 7):

```sh
./bazel-bin/compare_runs <dataset_dir_or_scsv> <control_trial> <candidate_trial> --quality 7
```

Quality selection mode when `--quality` is omitted (`common` by default, or `candidate`):

```sh
# Highest quality completed in both trials per font (default):
./bazel-bin/compare_runs <dataset_dir_or_scsv> <control_trial> <candidate_trial> --quality-mode common

# Highest quality completed in candidate per font:
./bazel-bin/compare_runs <dataset_dir_or_scsv> <control_trial> <candidate_trial> --quality-mode candidate
```
